PUBLIC TRANSPORT EFFICIENCY DASHBOARD

📌 Overview

The Public Transport Efficiency Dashboard is an interactive Power BI project developed to analyze and monitor the operational performance of public transportation systems. 

This dashboard provides clear insights into revenue generation, passenger trends, occupancy rates, delay patterns, and overall profitability across multiple cities and transport types. 

🎯 Project Objectives

Analyze total revenue and profitability

Monitor passenger trends over time

Measure occupancy rate and service utilization

Track on-time performance

Identify routes with high average delays

Compare city-wise transport efficiency

Trips

Routes

The data includes city details, transport type, route names, revenue, passenger count, delays, and maintenance records.

💡 Key Insights

Revenue varies significantly across cities.

On-time performance is relatively low and requires improvement.

Certain routes experience higher average delays.

The system is currently operating at a loss, indicating cost management challenges.

🚀 How to Use

Download the .pbix file from this repository.

Use the slicers to explore different cities, dates, and transport types.
